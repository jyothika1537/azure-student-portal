# Azure Services Required

## 1. Azure App Service
Used to host and run the Spring Boot Student Release Hub application in the cloud.

## 2. App Service Plan
Provides the compute resources required to run the App Service.

## 3. Deployment Slots
Production and Staging slots are used to deploy and test different application versions.

## 4. Application Insights
Used for monitoring application performance, failures, requests, and availability.

## 5. Azure Monitor
Used to monitor the health and performance of the deployed application.

## 6. Azure Resource Group
Used to organize and manage all Azure resources belonging to the project.

## 7. GitHub
Used for source code management and can be connected to Azure for application deployment.

## 8. Spring Boot Actuator
Used to provide health-check endpoints so that the application can be validated before deployment swapping.
