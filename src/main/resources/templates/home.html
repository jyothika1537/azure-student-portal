⚡ Slot Swap Architecture

1

Deploy to Staging

GitHub Actions packages and deploys Version 2 directly into the isolated staging slot.

2

Health Probe & Warm-up

Azure probes /actuator/health. The JVM JIT compiles and warms caches prior to any live traffic.

3

Zero-Downtime Swap

Virtual IP routing swaps instantaneously. Production visitors now instantly see Version 2 with 0 dropped requests.

4

Instant Rollback Safety

Previous Version 1 is preserved in the staging slot. If any anomaly occurs, swap again to immediately rollback.
