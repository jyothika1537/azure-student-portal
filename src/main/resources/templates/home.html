About the project

Student Release Hub

Student Release Hub demonstrates a safer cloud deployment strategy using Azure App Service deployment slots. A new application version is deployed to staging, validated using health checks and warm-up, and promoted to production through a controlled slot swap. The approach also supports rapid rollback when required.
